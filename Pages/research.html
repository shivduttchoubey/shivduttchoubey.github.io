Cryptography • CSPM

  • QuantumPosture: Built a specialized Cloud Security Posture Management extension that systematically scores Amazon S3, Azure Blob, and Google Cloud Storage buckets for HNDL vulnerability (0-100 risk score), analyzing underlying TLS ciphers, data shelf-life, and encryption tiers.
